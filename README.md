# Minecraft Realism (web build)

Play: https://ninjex2009-code.github.io/minecraft-realism-web/

A Minecraft-style voxel game made in Godot 4.7. This repo holds only the exported web build.

- **Multiplayer:** press Esc in a world, then **Open to Online** to get a room code. Friends join from
  Multiplayer > Join Room, in the browser or on desktop.
- **Shaders:** Options > Video > Shaders turns on the lite shader set in the browser.
- **Phones and tablets:** touch controls show up automatically. Landscape works best.
- `music_*.zip` (about 6 MB each) download after the game starts and are then cached.
